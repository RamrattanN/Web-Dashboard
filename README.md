## What this is
- Single file app `index.html` with Pointer Events drag and drop.  
- Works in current Chrome at 100 percent zoom.  
- Search inputs for Google, Bing, DuckDuckGo, and Perplexity with mic, image, and AI affordances where supported.  
- Settings dialog for wallpaper, columns, tile width, layout lock, and more.  
- Import and Export for backup portability.  

## Quick start
1. Open `index.html` in your browser.  
2. Click **Add link** to create your first tiles.  
3. Use **Settings** to adjust columns and tile width so the grid stays centered.  
4. Right click a tile for Open in new tab, Edit, Remove, Refresh icon.
